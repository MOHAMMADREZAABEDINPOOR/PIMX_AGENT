## ⚙️ تنظیمات

کلیدهای زیر از فایل نمونه یا کد استخراج شده‌اند؛ همه الزاماً اجباری نیستند. مقدار و پیش‌فرض را در همان فایل بررسی و اسرار را فقط در محیط محلی یا هاست تنظیم کنید.

| نام | کاربرد |
|---|---|
| `ALLOW_LOCAL_PROVIDERS` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `ALLOW_SHARED_PROVIDER_KEYS` | اعتبارنامه یا اتصال؛ خصوصی نگه دارید |
| `APP_DATA_DIR` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `APP_DATA_ENCRYPTION_KEY` | اعتبارنامه یا اتصال؛ خصوصی نگه دارید |
| `APP_PROXY_SECRET` | اعتبارنامه یا اتصال؛ خصوصی نگه دارید |
| `APP_RUNTIME` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `APP_SURFACE` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `APP_URL` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `GEMINI_API_KEY` | اعتبارنامه یا اتصال؛ خصوصی نگه دارید |
| `NEXT_PUBLIC_TURNSTILE_SITE_KEY` | تنظیم عمومی مرورگر؛ برای اسرار مناسب نیست |
| `TEST_BASE_URL` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `TRUST_PROXY` | تنظیم برنامه؛ تعریف را در منبع بررسی کنید |
| `TURNSTILE_SECRET_KEY` | اعتبارنامه یا اتصال؛ خصوصی نگه دارید |

اتصال‌های میزبانی: `ASSETS`, `DB`.

## 🌍 استقرار

برای مسیر Node از build و start و برای Cloudflare از اسکریپت‌های مخصوص package.json و اتصال‌های خودتان استفاده کنید. دیتابیس و اسرار باید جدا تنظیم شوند؛ راهنمای تکمیلی مخزن را بخوانید.

<a id="محدودیت‌ها"></a>

## 📌 محدودیت‌ها

دسترس‌پذیری، هزینه و محدودیت هر سرویس متفاوت است. دیتابیس و اتصال‌های Cloudflare باید با روش استقرار هماهنگ شوند. نام مدل در فهرست، تضمین دسترس‌پذیری آن نیست.
