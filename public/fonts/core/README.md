# Core fonts

Unmodified variable fonts from the Google Fonts repository. Each font's SIL Open Font License is included beside its binary.

- Vazirmatn: https://github.com/google/fonts/tree/main/ofl/vazirmatn
- Inter: https://github.com/google/fonts/tree/main/ofl/inter

Local CSS family aliases keep the default typography available offline and in printed PDF exports, without depending on third-party font requests.
